# V3.7 Integration Freeze — 实施计划

> **Product Track Version** — V3.7 是将 Agent 子线能力安全并回产品主线的版本。

## 目标

把 Agent 子线提前完成的能力安全并回产品主线：

- LLM-first time_management planner + 硬安全边界
- batch/defer 闭环
- ConversationService（服务层解耦）
- 版本语义重排
- 全程不破坏既有 75 条测试

## 技术决策

**LLM 接入方案：C-（LLM-first Planner with Deterministic Safety Boundary）**

- `time_management` 主链路改为 LLM-first planner（`LLMExperiencePlanner`）
- `SemanticFrameParser + ActionPlanner` 降级为 fallback / offline / mock baseline
- LLM 只能输出结构化 `ExperienceActionPlan`，不允许直接写数据库或调 Service
- 所有 LLM 输出经过：schema → toolName → args → PlanSafetyValidator → ConfirmationPolicy → ToolRouter → Service
