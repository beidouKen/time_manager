# V3.7 Integration Freeze — 闭合报告

> **Product Track Version** — V3.7 把 Agent 子线能力安全并回产品主线。

**完成日期**：2026-05-30

## 执行摘要

V3.7 Integration Freeze 已全部完成。所有计划内交付物均已实现，测试全绿，无新增 Breaking Change。

## 主要交付成果

### Phase A — 安全管道（Safety Plumbing）

✅ **ConversationService**：`chatStore` 不再直连 `SqliteConversationRepository`，统一通过服务层访问。

✅ **PlanSafetyValidator**：V3.7 统一安全闸门。所有 Planner（LLM 或规则）输出必经此验证，不合法计划在执行前被拒绝。

✅ **SinglePlanAction 类型**：顶层导出，供 Validator/Executor 共用。

✅ **ActionPlanner 改造**：batch_delete_tasks / defer_task 分支预先分解出 `params.actions[]`，为 confirmAction 执行闭环铺路。

✅ **executeActionList**：`AgentService.confirmAction()` 检测到 `actions[]` 时顺序执行所有子操作，支持 short-circuit 失败策略，每步写 ActionLog。

✅ **测试**：新增 v4-12（batch_delete confirm-then-execute）、v4-13（defer_task confirm-then-execute），全部通过。

### Phase B — LLM 接管链路

✅ **timeManagementSkill.md**：将 NL 理解规则、工具选择策略、时间表达式处理、clarification 触发条件写入 Skill 文件，与代码安全逻辑分离。

✅ **prompts.ts 重写**：`buildSystemPrompt()` 通过 `?raw` 动态加载 skill md，输出格式更新为 `LLMExperiencePlanResponse`。

✅ **LLMExperiencePlanResponse schema**（experienceSchemas.ts）：`kind` 直接对应 `ExperienceActionPlan.kind`，Zod 严格校验，减少 AgentService 层转换。

✅ **LLMExperiencePlanner**：实现 `PlannerPort`，调用 LLM → 解析 schema → 过 PlanSafetyValidator，全链路不触碰 ToolRouter/Service。LLM 不可用时抛 `LLMUnavailableError`。

✅ **CompositePlanner**：LLM-first + ActionPlanner fallback，透明降级。`lastUsedPlanner`/`lastFallbackReason` 供 AgentTrace 写入。

✅ **AgentService 接入**：默认使用 DeepSeekClient（读 `VITE_LLM_AGENT_ENABLED`），`llmClient: null` 显式禁用。`CompositePlanner` 作为 `plannerPort` 传入 `TimeManagementAgent`。

✅ **TimeManagementAgent planner 记录**：`agentTrace.planner` 从 `CompositePlanner.lastUsedPlanner` 读取（"llm" | "rule"）。

### Phase C — 只读 Handler

✅ **LLMChatExecutor**：只读文本调用器，绝对不调用 ToolRouter，剥离可能的 JSON 格式返回。

✅ **LLMDirectHandler 改造**：可选注入 executor，真实 LLM 回复或退回 boundary。

### Phase D — 测试与 Mock

✅ **MockLLMClient**：脚本驱动，支持精确匹配和错误注入（LLMError）。

✅ **createMockAgentHarnessWithLLM**：便捷工厂，默认 `llmClient: null` 防止测试中意外调用真实 API。

✅ **12 条 LLM 安全边界测试**（agent_v3_7_llm_safety.test.ts）：覆盖 happy path、未注册工具、policy 强制升级、batch-actions 闭环、defer 闭环、各类 LLM 错误降级。

✅ **6 条 ConversationService 测试**（ConversationService.test.ts）：CRUD smoke + metadata 保存。

### 附带 Bug Fix

✅ `dateFormatting.ts` 的 `getDateTimeParts()` 对无效/空时间字符串添加守卫（返回占位符），避免 `Invalid time value` 崩溃。
