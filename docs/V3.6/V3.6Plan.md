## V3.6.1：Agent Experience Pipeline Skeleton

目标：建立新 Agent pipeline，但只覆盖最核心场景。

实现链路：

UserInput
-> ConversationContextBuilder
-> SemanticFrameParser
-> ActionPlanner
-> ToolExecution
-> ResponseComposer
-> refreshHints
-> metadata.agentTrace

本阶段暂时不做完整 UniversalReferenceResolver，不做复杂 diagnose，不做完整 Verifier。

### 必须实现

1. ConversationContextBuilder
   - currentDatetime
   - timezone
   - currentTimelineDate / selectedDate
   - recentMessages
   - lastCreatedTaskId
   - lastMentionedTaskIds
   - lastScheduledTimeBlockIds
   - lastToolResults

2. SemanticFrameParser 最小版
   支持 userGoal：
   - ask_current_time
   - create_and_schedule_task
   - query_schedule
   - general_chat

   支持解析：
   - “现在是什么时候”
   - “我现在有一个临时的写作任务，大概10分钟，从现在开始”
   - “写作任务安排在哪”
   - “刚刚那个任务安排在哪”

3. ActionPlanner 最小版
   - ask_current_time 走 direct response，不调用工具。
   - create_and_schedule_task 调用 schedule_task。
   - “从现在开始”必须 exact scheduling，不能走 suggestSchedule。
   - query_schedule 优先使用 lastCreatedTaskId / lastMentionedTaskIds。

4. ResponseComposer 最小版
   禁止返回 action/tool/internal name。
   示例：
   - “现在是 2026年5月27日 20:17。”
   - “我已把‘临时写作任务’安排到现在开始，预计 10 分钟，时间段是 20:17 - 20:27。”
   - “这个任务安排在 20:17 - 20:27。”

5. Store refresh
   - 写操作返回 refreshHints。
   - chatStore 收到 refreshHints 后刷新 taskStore 和 timeBlockStore。

6. Trace
   metadata.agentTrace 至少记录：
   - rawInput
   - contextSnapshot
   - semanticFrame
   - actionPlan
   - toolResults
   - finalResponse

### 本阶段测试

必须通过：

1. “现在是什么时候？”
   - 返回自然时间
   - 不出现“回答当前时间”或 tool/action 名

2. “我现在有一个临时的写作任务，大概10分钟，从现在开始”
   - 创建 Task
   - 创建 TimeBlock
   - TimeBlock start 接近 currentDatetime
   - 返回 refreshHints

3. 接上一轮：“写作任务安排在哪？”
   - 能解析到刚创建任务
   - 返回对应 TimeBlock 时间段

4. pnpm.cmd exec tsc --noEmit
5. pnpm.cmd test
6. pnpm.cmd build
