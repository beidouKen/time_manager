## 2. 新增能力

### Production Embedding Provider

- `resolveEmbeddingProviderEnv()` / `createDefaultEmbeddingProvider()` / `describeEmbeddingProvider()`
- env：`VITE_RAG_EMBEDDING_PROVIDER`、`VITE_RAG_EMBEDDING_MODEL`、`VITE_RAG_EMBEDDING_DIMENSIONS`、`VITE_RAG_EMBEDDING_BASE_URL`、`VITE_RAG_EMBEDDING_API_KEY`
- 缺 key → **fallback deterministic**，不崩 App
- OpenAI-compatible：`embedBatch` 单次 POST；测试 fetch mock

### VectorStore Factory

- `VectorStoreFactory`：`sqlite_json` | `disabled`
- `DisabledVectorStore`：query `[]`，写 no-op
- `SqliteVectorStore`：`countEmbeddings` / `listIndexedDocumentIds` / `clearModel`

### Reindex 增强

- `RagIndexJob`：`total` / `skipped` / `durationMs` / `warnings`
- `clearVectorIndex` / `reindexForEmbeddingModelChange`
- keyword 失败 → `like-fallback` + success（不 fatal）

### Reranker

- `ScoreReranker`：seed_knowledge / high trust / 双通道轻微加权
- `RerankerFactory`：`none` | `score`（`VITE_RAG_RERANKER`）

### Evaluation Dataset

- `defaultRagEvalCases`：5 条固定 case
- 指标：`hitAtK`、`sourceTypeMatchRate`、`titleMatchRate`、`averageTopScore`
- `evaluateDefault()` / `RagAdminActions.runDefaultEvaluation()`

### Admin UI

- `RagAdminPanel` + Knowledge Manager Tab「引擎管理」
- 仅 `VITE_ENABLE_RAG_ADMIN=true` 可见
- Health / Rebuild / Evaluation 摘要；不暴露 API key

### Memory → RAG Bridge（预留）

- `MemoryToRagBridge`：`propose` / `validate` / `ingest`
- **UI actor 拒绝**；system actor 可写 `memory_summary` draft
- **未接入 App / Chat**

---

## 3. Feature flags

| 变量 | 默认 | 说明 |
|------|------|------|
| `VITE_RAG_ENGINE` | legacy | `self_hosted` 启用完整栈 |
| `VITE_RAG_EMBEDDING_PROVIDER` | deterministic | `openai_compatible` 需 key |
| `VITE_RAG_RERANKER` | none | `score` 规则重排 |
| `VITE_ENABLE_RAG_ADMIN` | false | 知识库管理器 Admin Tab |

---

## 4. 安全边界

- RAG 不写 tasks / time_blocks；不调 ToolRouter
- 默认不调用外部 embedding API
- 日志 / UI 不暴露 API key
- UI 禁止写 `memory_summary` / `system_guidance`
- Agent 不触发 rebuild（仅 Admin Panel）
