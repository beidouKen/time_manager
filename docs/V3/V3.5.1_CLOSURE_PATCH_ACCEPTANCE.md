# V3.5.1 Closure Patch 验收说明

## 自动化检查

- `pnpm.cmd exec tsc --noEmit`：通过。
- `pnpm.cmd build`：通过。
- 构建说明：Vite 仍会报告主 JS bundle 超过默认 chunk 大小的既有警告。

## 手工验收清单

- Chat 修改时间块：发送包含 `update_time_block` 和 `timeBlockId` 的 LLM tool plan，工具应能正确更新时间块。
- Chat 删除时间块：发送包含 `delete_time_block` 和 `timeBlockId` 的 LLM tool plan，工具应能正确删除时间块；旧字段 `blockId` 仍保持兼容。
- Delay 今天做：在 Delay 弹窗中选择当天时段后，`update_time_block` 必须使用 `timeBlockId` 执行。
- End Feedback 延长：无冲突时延长成功；有冲突时返回冲突提示，且不得写入数据库。
- PlanProposal 冲突：人为制造重叠目标时间段后，选择方案必须产生 `proposal_conflict_blocked`，且不得写入数据库。
- End Feedback split 部分失败：如果 `create_task` 成功但原时间块状态更新失败，弹窗必须保持打开，并显示部分成功错误提示。
- Delay 弹窗单实例：从 CurrentFocusCard 或 TimeBlockCard 打开 Delay 时，只能出现一个 `DelayChoiceDialog`。
- 构建：生产构建必须成功完成。

## 范围约束

- 不包含 V4 OCR 变更。
- 不包含 Memory/RAG 变更。
- 不包含数据库 schema 变更。
